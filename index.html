Quick Reference Guide

  1. Pick your forms — check the ones you need (816, 817, and/or 819); your BTH email says which.
  2. Type your name and school.
  3. Pick the month — it starts on this month; set a start/end day only for part of a month.
  4. Add your classes — type each class code in order; the times fill in for you.
  5. Set class times if needed — Does your class meet at a set day and time (like a Zoom class or an in-person class)? Turn on “meets at set times” and enter its days and times. Online classes with no set meeting time: skip this — the tool handles them.
  6. Generate — your finished PDFs download.
  7. Open each PDF in a reader that lets you sign (like Adobe Acrobat Reader or Mac Preview), sign it, and send it to BTH as usual.
